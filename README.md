# QuadAction

쿼터뷰 시점의 3D 액션 슈팅 게임입니다. 골드메탈의 "쿼터뷰 3D 액션게임" 강좌를 기반으로 시작해,
오브젝트 풀링·레벨업·로그라이크식 증강 시스템 등을 직접 확장하며 만든 학습용 프로젝트입니다.

- **엔진**: Unity 2022.3.30f1 (HDRP)
- **시점**: 쿼터뷰(Quarter View) 3D
- **장르**: 웨이브 방어 · 액션 슈팅

## 게임 소개

플레이어는 사방에서 몰려오는 적을 상대로 스테이지를 하나씩 돌파해 나갑니다.
근접 무기와 원거리 무기를 상황에 맞게 교체하고, 회피 구르기와 수류탄을 활용해
점점 강해지는 적의 물량을 버텨내야 합니다.

스테이지를 클리어하면 상점 구역으로 돌아와 코인으로 탄약·체력·수류탄·무기를 구매하고
다음 전투를 준비합니다. 적을 처치해 얻은 경험치가 가득 차면 레벨업하며,
그때마다 무작위로 제시되는 3개의 증강 중 하나를 골라 캐릭터를 성장시킵니다.
5스테이지마다 미사일과 낙석, 도발 공격을 퍼붓는 보스가 등장합니다.

목표는 죽기 전까지 최대한 높은 점수를 쌓는 것. 최고 점수는 저장되어 다음 플레이에서 갱신에 도전할 수 있습니다.

## 주요 기능

### 전투
- 이동 / 걷기 / 점프 / 회피 구르기
- 무기 3종 슬롯 교체 — 근접(Melee) / 원거리(Range)
- 마우스 조준 사격, 재장전, 탄피 배출 연출
- 수류탄 투척 (조준 위치로 포물선 투척)
- 적 타입 A·B·C (근접·원거리 혼합)와 보스(D)

### 스테이지 & 상점
- 스테이지가 진행될수록 적 수와 종류 증가
- 스테이지 사이 상점 구역: 아이템 상점 / 무기 상점
- 스타트 존에 진입하면 다음 전투 시작
- 5스테이지 주기 보스전 (예측 사격 · 미사일 난사 · 낙석 · 도발)

### 성장 시스템
- 경험치 획득 → 레벨업
- 레벨업 시 무작위 증강 3택 1 (로그라이크 방식)
  - 최대 체력 증가 (+ 체력 완전 회복)
  - 코인 획득량 배율 증가
  - 최대 탄약 증가
- 획득한 증강은 아이콘과 레벨로 표시, 중첩 획득 가능
- `ScriptableObject`(`Effect`) 기반으로 증강 데이터 관리 → 새 증강 추가 용이

### 구조 / 최적화
- **PoolManager**: 적 오브젝트 풀링, 풀 부족 시 자동 확장
- **EffectManager**: 증강 선택·적용을 `Dictionary<EffectType, Action>` 매핑으로 처리해 분기 제거 및 확장성 확보
- **EffectManager(파티클)**: 이펙트 재사용 관리
- 메뉴 카메라 / 게임 카메라 분리, `GameManager`가 UI·스테이지 흐름 총괄
- 최고 점수는 `PlayerPrefs`로 저장

## 조작

| 입력 | 동작 |
|---|---|
| WASD | 이동 |
| Shift (Walk) | 걷기 |
| Space | 점프 |
| 마우스 좌클릭 | 공격 / 조준 |
| 마우스 우클릭 | 수류탄 |
| R | 재장전 |
| E (Interaction) | 상호작용 (상점 · 아이템 · 스타트 존) |
| 1 / 2 / 3 | 무기 교체 |
| 우클릭 이동 중 Space | 회피 구르기 |

## 실행 방법

1. Unity 2022.3.30f1 (LTS)로 프로젝트를 엽니다.
2. `Assets/00.Scenes/SampleScene.unity` 를 엽니다.
3. Play 버튼으로 실행합니다.
